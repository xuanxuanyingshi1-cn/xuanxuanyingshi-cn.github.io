NOTE 01

萱萱影视是做什么的站点？

萱萱影视是一个影视条目聚合导航与更新索引站，主要做条目分类整理、追更台账、番剧归档与影人档案检索，帮助浏览者快速定位想了解的条目。

NOTE 02

站点是否支持手机浏览？

支持。全站采用弹性栅格与流式布局，覆盖 380px 至桌面宽屏区间；标本卡与压花图鉴在窄屏转单列，便签墙自动收缩密度。

NOTE 03

条目与台账多久更新一次？

院线条目库每日更新，剧集追更台账每周核对，动漫番剧索引按季度归档，影人档案随作品收录滚动补充，记录可在更新轨迹中回溯。

NOTE 04

花瓣点亮的瓣数怎么读？

十枚花瓣对应该栏目条目占总量的比例，每点亮一枚代表约 10%；右侧标注累计条数与精确百分比，不引用任何外部播放数据。

NOTE 05

如何快速找到想了解的条目？

先确定内容形态进入对应分类，再用类型、地区、年份标签组合缩小范围，最后核对条目的在播或完结状态，即可定位目标条目。

NOTE 06

是否提供影视文件的存储或下载？

不提供。萱萱影视仅做条目索引与聚合导航，不存储、不上传、不分发任何影音文件，也不提供任何未经授权的播放或下载服务。
